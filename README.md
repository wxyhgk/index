# MacShot

macOS 截图工具：**冻结截图 → 就地标注 → 钉图 / 复制 / 保存 → 自动入库 → 全文检索**，全程非破坏性编辑。

核心特性：

- **冻结截图，所见即所得** —— 按下快捷键即把每块屏定格成位图，选区、标注全程对着冻结画面做；确认后零延迟（只是 cropping，不二次截屏），在工具条上停留多久，存下来的都是框选时那一帧
- **内联标注** —— 矩形 / 椭圆 / 箭头 / 文字 / 高亮 / 马赛克，直接画在冻结画面上；预览与导出走同一份渲染代码，不存在"预览一个样、导出另一个样"
- **钉图** —— 截图钉在屏幕最上层，滚轮缩放、透明度可调，还能接着用同一条工具条继续画
- **非破坏性修订链** —— 原图落盘后永不修改，所有标注（含裁剪）都是 append-only 的结构化图层版本，编辑历史可无限回溯
- **OCR 全文搜索** —— 截图自动过 Vision OCR，图库里可以直接搜"截图里的字"；FTS5 trigram 分词，中文子串友好
- **放大镜取色器** —— 选区时光标旁实时显示像素放大预览、#RRGGBB 色值和坐标，一键复制色值
- **多显示器** —— 每块屏各自冻结，按鼠标位置决定焦点屏

## 构建与首次运行

```bash
./scripts/make-dev-cert.sh   # 只需跑一次，创建固定签名身份
./build.sh                   # 产出 build/MacShot.app
open build/MacShot.app
```

首次运行需要在 **系统设置 → 隐私与安全性 → 屏幕录制** 中勾选 MacShot，然后**重启 App**。

### 关于「每次构建都要重新授权」

macOS 的 TCC 是这样认 App 的：

- **ad-hoc 签名**（`codesign -s -`）没有身份信息，TCC 只能记二进制的 **cdhash** ——
  代码改一行哈希就变，授权立刻失效。
- **固定证书签名**下，TCC 记的是 designated requirement：
  `identifier "com.wxyhgk.macshot" and certificate leaf = H"<证书指纹>"`
  —— 与代码内容无关，重新构建多少次都不变。

`scripts/make-dev-cert.sh` 会在登录钥匙串里自签一张代码签名证书（不需要 Apple 开发者账号），
`build.sh` 会自动优先使用它。签名身份优先级：Developer ID → MacShot Dev（本地自签）→ ad-hoc。

注意 **App 路径也要保持稳定**，`build/MacShot.app` 换位置会被当成另一个 App 重新问一次权限。

撤销：打开「钥匙串访问」，在登录钥匙串里删掉名为 `MacShot Dev` 的证书。

## 使用

### 全局快捷键

| 操作 | 默认值 |
|---|---|
| 截图 | `⌃⌘A` |
| 打开图库 | `⌃⌘G` |

两个都**可以在设置里自定义**（菜单栏图标 → 设置… → 快捷键，或 `⌘,`），改完立即生效，无需重启。录制控件会拒绝没有修饰键的组合。菜单栏里显示的始终是当前生效的键。

### 截图交互

- **拖拽** → 自由选区；**单击窗口** → 整窗捕获（悬停蓝框高亮）
- 选区确认后可继续调整：**8 个控制点**拖拽改大小，**拖内部**整体移动，拖过对边自动翻转
- **方向键**微调选区：默认 1pt，`⇧` 十倍步进，`⌥` 改为调尺寸
- **放大镜取色器**：挑位置阶段光标旁浮出像素放大预览（带网格）、`#RRGGBB` 色值和像素坐标，按 **`C`** 复制色值（`⌘C` 仍是复制图片）。自动避让屏幕边缘；设置里可关
- **`ESC` / 右键** 逐级退出：先放下画笔，再取消选区 —— 不会一下子把画到一半的东西全丢掉

### 标注

选区确认后直接在冻结画面上画。工具快捷键（截图覆盖层和钉图窗口是同一份表）：

| 键 | 工具 |
|---|---|
| `V` | 指针（调整选区） |
| `R` | 矩形 |
| `A` | 箭头 |
| `T` | 文字（点击即就地输入，空文字自动丢弃） |
| `P` | 马赛克 |
| `O` | 椭圆 |
| `H` | 高亮 |

`⌘Z` 撤销。右键逐级退出（文字输入 → 工具 → 选区）。

**工具条**是精简式的：指针模式下只显示工具和动作；选中某个工具后才展开颜色（4 色）和粗细（3 档）；有标注后才出现撤销。椭圆和高亮不常驻工具条，只留快捷键 —— 用快捷键激活后会临时显示在条上，让你看得到当前选中的是什么。宽度不够时自动折行。

### 确认与出口

- 工具条动作：**钉图 / 复制 / 保存**（`⌘C` 复制、`⌘S` 保存）
- **回车**的行为可在设置里选：「完成并复制」（默认）或「完成（不复制）」—— 后者明确不碰剪贴板，即使全局自动复制开着
- 设置里还可开关：截图后自动复制到剪贴板、自动 OCR、标注默认颜色和粗细

### 钉图窗口

- 工具条常驻在图片下方的条带里，和截图时是**同一条工具条、同一套快捷键**，钉完图可以接着画 —— 新画的标注作为修订追加，和截图时画的、图库里改的走同一条链
- 拖拽移动，**滚轮**缩放，**⌘+滚轮**调透明度；缩放到多大，笔画在屏幕上都是同样粗细
- **双击**复制，`⌘C` 复制，`⌘S` 保存，`ESC` 关闭（拿着画笔时先放下画笔）

### 图库与搜索

`⌃⌘G` 打开图库。搜索框可搜 **App 名、窗口标题、网址、以及截图里被 OCR 出来的文字**。FTS5 用 trigram 分词器，中文子串直接命中（unicode61 不切分 CJK，所以特意换掉了）。双击一张截图进入编辑器，可查看和继续追加修订。

每张截图自动采集元数据：App 名 / bundleID / 版本、窗口标题、显示器信息，浏览器截图还会通过 AppleScript 异步回填网址（Safari / Chrome / Edge / Arc / Brave / Vivaldi，需「自动化」授权，失败静默跳过）。

## 存储与数据模型

```
~/Library/Application Support/MacShot/
  originals/<sha256>.png    原图，写入后永不修改（内容寻址，天然去重）
  thumbnails/<sha256>.jpg
  index.sqlite              元数据 + 修订 + FTS5 全文索引
```

原图是不可变的字节。标注以**结构化图层**存在修订链里：

```
shot (原图元数据)
 └── revision  (append-only，parentID 指向上一版)
       └── layers: [Layer]   矩形/椭圆/箭头/直线/文字/高亮/马赛克/裁剪
```

每次保存都是 `INSERT`，从不 `UPDATE` 旧记录 —— 编辑历史天然完整、可无限回溯。裁剪同样是一个图层，不动原图。只有交给用户的产物（剪贴板 / 钉图 / 导出）才由 `LayerRenderer` flatten 渲染一次。

派生属性（OCR 文本等）走通用的 `shotAttribute` 表 + 独立 FTS 索引，搜索时 UNION 两张 FTS 表 —— 新的后处理器产出的文本自动可搜，不必改 schema 或查询。

## 架构

整个系统只有**三个注册制扩展点**，新功能一律挂在这三个之一上，「加功能 = 加一个文件 + 注册一行」，不改中间的编排代码：

| 扩展点 | 回答的问题 | 例子 |
|---|---|---|
| `CaptureAction`（出口） | 结果怎么出去 | 钉图、复制、保存；将来的上传图床、发 Slack |
| `CapturePostProcessor`（中间） | 落库后派生什么 | OCR、浏览器网址；将来的 CLIP 向量、自动打标签 |
| `ToolbarControl`（控件） | 工具条上放什么 | 工具、颜色、粗细、撤销；上下文相关显隐 |

其它值得一提的决定：图层坐标用 phantom type（`Layers<CanvasSpace>` / `Layers<ImageSpace>`）区分，忘换算或换算两次都是**编译错误**而不是标注错位；绘制原语只存在于 `LayerRenderer` 一个文件，四条预览/导出路径同源；工具快捷键表只有 `AnnotationTool.shortcuts` 一份，设置页的说明文本由它生成；剪贴板、存盘面板、窗口生命周期等平台副作用各自收敛到 `Platform/` 下的单一实现。

依赖方向、契约的完整定义和落地阶段见 **[ARCHITECTURE.md](ARCHITECTURE.md)**。

## 已知边界

- 选区不支持跨显示器拖拽（限制在起始那块屏内）
- 图层画完后暂不能选中拖动/缩放，只能撤销重画
- 修订历史是线性链，`parentID` 已预留但 UI 未做分叉
- Firefox 取不到网址（不支持 AppleScript，需退回 Accessibility API）

## 路线图

1. **图层直接操作** —— 选中后拖拽 / 缩放 / 改样式
2. **自动分类**（正在做）—— bundleID 本身就是最强分类信号（Xcode→代码、Figma→设计），先做规则表再上模型
3. **CLIP 语义搜索** —— image embedding 存进 SQLite，语义搜索 + zero-shot 分类，作为一个 `CapturePostProcessor` 挂上去
4. **滚动截图 / 延时截图** —— 等 `CaptureSource` 入口契约落地（ARCHITECTURE.md 阶段 4）
5. **Developer ID 签名 + 公证**
