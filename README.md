# Index

个人视觉资料库：**捕获 / 导入 → 就地标注 → 钉图 / 复制 / 保存 / 上传 → 自动入库 → 分类与检索**，全程非破坏性编辑。

当前用户品牌为 **Index**。为保持屏幕录制授权、图库路径和既有自动化兼容，工程 target、
`MacShot.app` 固定路径、Bundle ID 与 `~/Library/Application Support/MacShot/` 暂不改名。

核心特性：

- **冻结截图，所见即所得** —— 按下快捷键即把每块屏定格成位图，选区、标注全程对着冻结画面做；确认后零延迟（只是 cropping，不二次截屏），在工具条上停留多久，存下来的都是框选时那一帧
- **内联标注** —— 矩形 / 椭圆 / 箭头 / 直线 / 文字 / 高亮 / 马赛克 / 序号 / 聚光灯 / 测量 / 裁剪，直接画在冻结画面上；图层可选中、拖动、拖角缩放、删除、改样式，撤销重做（`⌘Z` / `⇧⌘Z`）完整覆盖每一步；预览与导出走同一份渲染代码，不存在"预览一个样、导出另一个样"
- **真·整窗捕获** —— `⌥`+单击拿到**不被遮挡的完整窗口**：别的窗口挡住的部分也在，圆角外真透明，系统阴影可选
- **带壳截图** —— 内容套进 macOS 窗口壳或浏览器壳，纯矢量零素材；浏览器壳的地址栏自动填**真实网址和标题**（来自元数据库，竞品的壳都是空壳）
- **水印** —— 右下角 / 居中 / 平铺三种位置，白字黑描边深浅底通用，可选导出自动加
- **快速暂存栏** —— 截完右下角浮出小卡片，直接拖出去就是 PNG 文件，丢进聊天窗口或邮件
- **钉图** —— 截图钉在屏幕最上层，滚轮缩放、透明度可调，`⌘T` 鼠标穿透当参考图，还能接着用同一条工具条继续画
- **3D 分子钉图** —— 复制 XYZ 文本后按 `⌃⌘M`，直接生成置顶的交互式分子窗口；旋转到合适视角后点“定格为图片”，原地进入普通钉图与 Tool Palette，可继续标注 / 复制 / 保存 / 上传。定格图的原始 XYZ 作为独立附件保留，分子图标可复制坐标、用默认应用打开可编辑工作副本或重新进入 3D
- **非破坏性修订链** —— 原图落盘后永不修改，所有标注（含裁剪）都是 append-only 的结构化图层版本，编辑历史可无限回溯
- **智能图库** —— 自动分类、自定义标签、收藏、时间分组、多选批量操作、以图搜图、同源时间线对比，还能用自然语言做 CLIP 语义搜索
- **本地图片导入** —— 图库顶栏选择或直接拖入 PNG / JPEG / HEIC / TIFF；原图复制进 Index 后即可沿用收藏、专题、标注、复制与导出
- **Edge 图片收藏 Demo** —— 网页图片右键「保存图片到 Index 图库」，图片内容经本机 Native Messaging 连接器进入同一套导入与收藏链路，并保留来源页面网址
- **OCR 全文搜索** —— 截图自动过 Vision OCR，图库里可以直接搜"截图里的字"；FTS5 trigram 分词，中文子串友好
- **智能脱敏** —— 自动检测邮箱 / 密钥 / 银行卡 / 手机号 / IP / 人脸，图库里一键打码
- **放大镜取色器** —— 选区时光标旁实时显示像素放大预览、#RRGGBB 色值和坐标，一键复制色值
- **多显示器** —— 每块屏各自冻结，按鼠标位置决定焦点屏

## 构建与首次运行

```bash
./scripts/make-dev-cert.sh   # 只需跑一次，创建固定签名身份
./build.sh                   # 产出 build/MacShot.app
open build/MacShot.app
```

改完代码提交前跑一遍门禁（构建 + 测试 + 架构纪律，约半分钟）：

```bash
./scripts/check.sh
```

CI 跑的是同一个脚本。流水线与 runner 的搭建见 [docs/ci.md](docs/ci.md)。

公共 GitHub CI 使用 `macos-15` runner，只执行构建、测试和架构纪律，不触发截图、录屏、
Release 签名或 TCC 授权。隐私与联网边界见 [PRIVACY.md](PRIVACY.md)。

首次运行需要在 **系统设置 → 隐私与安全性 → 屏幕录制** 中勾选 Index，然后**重启 App**。

### 关于「每次构建都要重新授权」

macOS 的 TCC 是这样认 App 的：

- **ad-hoc 签名**（`codesign -s -`）没有身份信息，TCC 只能记二进制的 **cdhash** ——
  代码改一行哈希就变，授权立刻失效。
- **固定证书签名**下，TCC 记的是 designated requirement：
  `identifier "com.wxyhgk.macshot" and certificate leaf = H"<证书指纹>"`
  —— 与代码内容无关，重新构建多少次都不变。

`scripts/make-dev-cert.sh` 会在登录钥匙串里自签一张代码签名证书（不需要 Apple 开发者账号），
`build.sh` 会自动优先使用它。签名身份优先级：Developer ID → MacShot Dev（本地自签）。没有稳定证书时构建会直接失败；只有明确设置 `MACSHOT_ALLOW_ADHOC=1` 才允许生成不保留 TCC 身份的临时包。

另一个同样重要的边界是：**不能在 MacShot 仍运行时原地删除并重建 `.app`**。旧进程的 audit token 仍属于旧代码，而同一路径若已变成新签名内容，TCC/replayd 会看到不一致的客户端身份。现在 `build.sh` 会先在 `build/.MacShot-stage.*` 完整组装、签名并验证，随后退出旧进程、原子替换 bundle；如果构建前 App 正在运行，还会自动启动新版本。正常开发构建不需要重启电脑。

注意 **App 路径也要保持稳定**，`build/MacShot.app` 换位置会被当成另一个 App 重新问一次权限。

撤销：打开「钥匙串访问」，在登录钥匙串里删掉名为 `MacShot Dev` 的证书。

## 使用

### 全局快捷键

| 操作 | 默认值 |
|---|---|
| 截图 | `⌃⌘A` |
| 延时截图 | `⌃⌘D` |
| 滚动截图 | `⌃⌘S` |
| 录屏 | `⌃⌘R` |
| 打开图库 | `⌃⌘G` |
| 从剪贴板钉住 3D 分子 | `⌃⌘M` |

六个都**可以在设置里自定义**（菜单栏图标 → 设置… → 快捷键，或 `⌘,`），改完立即生效，无需重启。录制控件会拒绝没有修饰键的组合。菜单栏里显示的始终是当前生效的键。

**延时截图**：等几秒再定格屏幕，留时间去展开菜单、悬停出提示。延迟秒数在设置里选（3 / 5 / 10 秒），等待期间主屏右下角显示大数字倒计时，不抢焦点；点击倒计时面板、按 `⎋` 或再按一次快捷键都能取消。

### 截图交互

- **拖拽** → 自由选区；**单击窗口** → 整窗捕获（悬停蓝框高亮，从冻结画面裁出可见部分）
- **`⌥`+单击窗口** → 真·整窗捕获：按住 `⌥` 高亮变紫并标注「完整窗口」，拿到的是**不被遮挡的完整窗口** —— 被别的窗口挡住的部分也完整呈现，窗口圆角外真透明（PNG 保留 alpha），系统阴影可在设置里关。捕获失败（窗口已关）时退回冻结画面裁剪
- 选区确认后可继续调整：**8 个控制点**拖拽改大小，**拖内部**整体移动，拖过对边自动翻转
- **方向键**微调选区：默认 1pt，`⇧` 十倍步进，`⌥` 改为调尺寸
- **放大镜取色器**：挑位置阶段光标旁浮出像素放大预览（带网格）、`#RRGGBB` 色值和像素坐标，按 **`C`** 复制色值（`⌘C` 仍是复制图片）。自动避让屏幕边缘；设置里可关
- **`ESC`** 在编辑/标注后第一次退出整套编辑态、第二次取消截图；中性态下一次退出。**右键**保留更细的逐级退出

**滚动截图**（`⌃⌘S`）：框选区域后**你自己滚动页面**，Index 自动拼接 —— 不合成滚动事件，所以不需要辅助功能权限。控制条实时显示已拼接高度，滚太快会提示放慢（宁可暂停不错拼）；固定导航栏只出现一次。完成后长图入库并直接打开编辑器。已知不支持横向滚动，视差/动画背景的页面可能拼不上。

**录屏**（`⌃⌘R`，macOS 15 起）：框选区域回车开始，菜单栏变红点计时，再按一次停止。产物是 mp4（30fps 含光标，无音频），30 秒内的可一键转 GIF。默认同时进入「图库 → 录屏」并显示首帧封面；双击或回车播放，拖出卡片得到原始 mp4。视频文件保存在 `~/Library/Application Support/MacShot/recordings/`，可在设置里关闭自动入库。

### 标注

选区确认后直接在冻结画面上画。工具快捷键（截图覆盖层、钉图窗口、图库编辑器是同一份表）：

| 键 | 工具 |
|---|---|
| `V` | 指针（选中 / 拖动图层，调整选区） |
| `R` | 矩形 |
| `A` | 箭头 |
| `T` | 文字（点击即就地输入，空文字自动丢弃） |
| `P` | 马赛克 |
| `O` | 椭圆 |
| `H` | 高亮 |
| `L` | 直线 |
| `X` | 裁剪（`C` 被取色器占用） |
| `N` | 序号（点击落点，编号自动递增） |
| `S` | 聚光灯（矩形亮区，区域外整体压暗） |
| `M` | 测量（标注图像像素尺寸） |

`⌘Z` 撤销、`⇧⌘Z` 重做 —— 操作栈完整覆盖画、移动、删除、改样式，不只是"删掉最后一层"。右键逐级退出（文字输入 → 工具 → 选区）。

**图层直接操作**：指针模式下点击图层即选中（虚线框提示），拖拽移动，**拖 8 个控制点缩放**，`⌫` 删除；选中后再点颜色 / 粗细就地改样式。缩放按图层语义来：直线 / 箭头只动被拖的那一端（方向不变），序号恒保持圆形，文字随高度改字号，测量改完自动重算标签，马赛克按新范围重新取样 —— 截图覆盖层、钉图、编辑器三处行为一致。

**测量**（`M`）：拖一个矩形，中央标签显示 `W × H px`；近似横 / 竖的拖拽自动吸附成单维，画成双箭头线段只标长度。数值是**图像真实像素**（Retina 上就是 2 倍于"点"的尺寸），预览和导出显示同一个数 —— 标 UI 间距、量设计稿都不用再开取色器数格子。

**工具条**是精简式的：指针模式下只显示工具和动作；选中某个工具后才展开颜色（4 色）和粗细（3 档）；有标注后才出现撤销。常驻条上的是矩形 / 箭头 / 文字 / 马赛克 / 序号，其余（椭圆 / 高亮 / 直线 / 裁剪 / 聚光灯 / 测量）只留快捷键 —— 激活后会临时显示在条上，让你看得到当前选中的是什么。宽度不够时自动折行。

工具条上还有一个**美化**开关（sparkles 图标）：导出的成品垫上渐变 / 纯色背景，内容圆角 + 投影 + 四周留白。画布预览刻意不变（编辑几何不受牵连），按钮高亮表达状态；背景预设（蓝紫渐变 / 日落渐变 / 灰黑渐变 / 纯色）在图库编辑器里切换。

**带壳截图**（macwindow 图标）：导出成品套进 **macOS 窗口壳**（标题栏 + 红绿灯）或**浏览器壳**（再加一条带小锁的地址栏），整体圆角裁剪，纯矢量绘制零素材。标题栏和地址栏填的是**真实元数据** —— 窗口标题和网址来自元数据库，竞品的壳都是空壳。网址是落库后异步回填的，所以截图当下开壳地址栏是空胶囊，编辑器 / 钉图里开壳就有。壳是一个图层，进修订链可撤销；与美化叠加时壳在内、背景在外。和美化一样，画布预览不变，只在导出 / 复制 / 保存时生效；壳样式在图库编辑器里切换。

**水印**（signature 图标）：文字水印，**右下角 / 居中斜排 / 斜向平铺**三种位置，白字细黑描边，深浅底上都可见。默认文案、位置、透明度在「设置 → 标注」里配；「导出自动加水印」开关（默认关）只作用于新截图，文案为空不生效，手动开关不受它影响。水印也是图层：可撤销、可回溯、图库编辑器里能删。与美化不同，水印在预览里就画出来 —— 它影响构图判断。

### 确认与出口

- 工具条动作：**钉图 / 复制 / 保存 / 上传 / 报告 / 取字**（`⌘C` 复制、`⌘S` 保存）
  - **上传** —— 传到自定义 HTTP 图床，链接进剪贴板（见下方「上传图床」）
  - **报告** —— 把 App 名 / 版本 / Bundle ID / macOS 版本 / 芯片 / 窗口标题 / 网址 / 图片尺寸整理成 Markdown Bug 报告模板放进剪贴板，直接贴进 issue / 群聊
  - **取字** —— 框住的区域过 OCR，文字直接进剪贴板，一步完成（只在截图工具条上；钉图里同一张图早已入库，OCR 结果去图库详情栏整段复制）
- **回车**的行为可在设置里选：「完成并复制」（默认）或「完成（不复制）」—— 后者明确不碰剪贴板，即使全局自动复制开着
- 设置里还可开关：截图后自动复制到剪贴板、自动 OCR、自动分类、敏感内容检测、语义搜索、标注默认颜色和粗细、登录时启动（原生 `SMAppService`，等待系统批准时如实显示并给出系统设置入口）

### 上传图床

uPic 式的自定义 HTTP API 上传，PicGo / SM.MS / Chevereto 类图床都能覆盖。在「设置 → 上传」里配置：

- **接口地址** —— multipart/form-data POST 的目标
- **文件字段名** —— 默认 `file`（PicGo / uPic 系图床通常如此）
- **请求头** —— 每行一条 `Key: Value`，放 token 用
- **响应取链接** —— JSON 响应里链接的点分路径（如 `data.url`），留空表示整个响应体就是链接
- **链接格式** —— 纯链接或 Markdown `![](url)`

上传成功后链接自动进剪贴板。未配置时点「上传」会提示先去设置。

### 文件名、自动副本与存储清理

- **文件名模板** —— 默认使用紧凑时间名，如 `20260813-143208.png`；支持 `{dateCompact}` / `{timeCompact}` / `{date}` / `{time}` / `{app}` / `{title}` / `{name}`，保存面板、图库导出、自动副本走同一份模板，重名自动追加序号
- **自动副本**（默认关）—— 每张截图入库后自动写一份成品 PNG 到指定文件夹，重名自动加序号。配合 Obsidian / 笔记软件的监听文件夹，截图直接进知识库
- **存储自动清理**（默认关）—— 启动时删除超过 7 / 30 / 90 天的旧截图，每次最多 200 张，删不完的下次接着删。**收藏的、打过标签的、标注过的永远不删** —— 「标注过」= 修订数 > 1，任何一笔标注都让它结构上进不了清理候选

### 快速暂存栏

截完图（选「钉图」除外）屏幕右下角浮出一张暂存卡片：**直接拖出去就是 PNG 文件**（含标注的成品，文件名走模板），丢进聊天窗口、邮件、访达都行。最多堆叠 3 张，挤掉最旧的；15 秒无操作自动淡出，悬停暂停计时并浮出关闭按钮；双击打开图库定位到该张。面板不抢焦点、永不成为 key 窗口。设置「通用」页可关。

### 钉图窗口

- 工具条常驻在图片下方的条带里，和截图时是**同一条工具条、同一套快捷键**（上传、报告也在），钉完图可以接着画 —— 新画的标注作为修订追加，和截图时画的、图库里改的走同一条链
- 拖拽移动，**滚轮**缩放，**⌘+滚轮**调透明度；缩放到多大，笔画在屏幕上都是同样粗细
- **`⌘T` 鼠标穿透** —— 窗口压暗、边框变虚线，点击直接落到底下的内容上，当参考图不再挡手；穿透后窗口收不到任何事件（`⌘T` 也按不进去了），解除走菜单栏「解除钉图穿透」一键恢复全部
- **双击**复制，`⌘C` 复制，`⌘S` 保存，`ESC` 关闭（拿着画笔时先放下画笔）
- XYZ 定格得到的钉图多一个**分子图标**：可复制原始 XYZ、用系统默认应用打开 `.xyz` 工作副本，或重新进入交互式 3D。图标和坐标附件只存在于 Index，导出的 PNG 不会携带或烧入这些信息

### 图库与搜索

`⌃⌘G` 打开图库。左侧筛选侧边栏（全部 / 收藏 / 自动分类 / 标签 / 按 App，都带计数徽章和分类色点，App 行显示真实图标，应用超过 8 个默认只显示前 5），中间缩略图网格按时间分组（今天 / 昨天 / 本周 / 本月 / 更早），分组标题**吸顶**并带计数，底部缩放条调卡片大小；右侧详情栏是**可折叠的 inspector** —— 工具栏按钮开关，开合状态跨启动记住。卡片本身就是信息面板：左下角分类胶囊、右下角标注角标、悬停浮出像素尺寸条、收藏星带弹跳动画；深色模式不靠阴影靠提亮。卡片可以直接**拖出去** —— 落到访达 / 聊天窗口就是含标注的成品 PNG。窗口位置和缩放档都会记住上次的样子。

图库里的名称是可编辑元数据：右键或按 `F2` 重命名，不会改动按 SHA-256 内容寻址的真实原图文件；清空名称即可恢复原文件名或窗口标题。

图库顶栏的「导入」支持一次选择多张 PNG / JPEG / HEIC / TIFF，也可把这些图片直接拖进图库区域。导入时会复制一份不可变原图到 Index，之后移动或删除外部文件不影响图库内容。

**Microsoft Edge Demo**：运行 `./scripts/install-edge-demo.sh`，然后在 Edge 的
`edge://extensions` 开启开发人员模式，选择「加载解压缩的扩展」，加载
`BrowserExtensions/Edge`。之后右键网页中的 PNG / JPEG / HEIC / TIFF 图片即可发送到
Index；详细边界与卸载方法见 [Edge Demo 文档](BrowserExtensions/Edge/README.md)。

**图库按键**：

| 键 | 行为 |
|---|---|
| `空格` | Quick Look 大图预览（原图；面板翻页与网格选中双向同步） |
| `方向键` | 走格移动选中；`⇧`+方向键扩展多选 |
| `回车` | 截图打开编辑器；录屏播放原始 MP4 |
| `⌘A` | 全选 |
| `⌘⌫` | 删除选中（带确认，删除后选中顺移到相邻一张） |
| `⌘` 点击 / `⇧` 点击 | 加减选 / 锚点到落点的范围选（跨分组） |
| `Esc` | 多选收拢回单选 |

**多选与批量操作**：选中多张时详情栏切换成批量面板（已选张数 + 2×2 拼贴预览），批量收藏 / 导出 / 删除；右键选中集合内任意一张出批量菜单（标题带张数）。批量导出选个目录，逐张后台渲染成品按文件名模板写入，重名自动加序号。

**自定义标签**：自动分类之外你自己的组织方式。详情栏「标签」卡片里点「+ 标签」输入，回车提交，输入时按使用量给建议，可连续打；胶囊悬停出 ✕ 移除。侧边栏「标签」区按数量降序，右键重命名 / 删除（只删标签，截图不动）。标签名自动进全文索引，搜索框直接搜得到；打过标签的截图**豁免存储自动清理**。

**自动分类**是规则分类器：bundleID 本身就是最强分类信号（Xcode → 代码、Figma → 设计），分成代码 / 浏览器 / 聊天 / 设计 / 终端 / 文档 / 笔记 / 影音 / 效率 / 其它，落库后台完成，可在设置里关。

搜索框有两种模式：

- **精确** —— 搜 App 名、窗口标题、网址、以及截图里被 OCR 出来的文字。FTS5 用 trigram 分词器，中文子串直接命中（unicode61 不切分 CJK，所以特意换掉了）
- **语义** —— 用自然语言描述画面（如 "blue gradient dashboard"），按回车搜索，结果按相似度排序。用的是 MobileCLIP 模型，**约 111 MB，在设置里按需下载**，推理全部在本机完成；模型为英文训练，英文描述效果最好

详情栏与卡片上的动作（详情栏里「编辑」是主按钮，收藏 / 钉图 / 导出是图标组，其余收进「更多」菜单；来源 / 识别 / 修订历史分组成卡片，修订历史连线成时间线）：

- **收藏** —— 卡片悬停加星，侧边栏「收藏」一键筛选
- **出处** —— 回到截图来的地方：有网址开默认浏览器，否则激活来源 App
- **相似** —— Vision 特征指纹（FeaturePrint）以图搜图，零下载、无需模型
- **时间线** —— 同源截图（同一网址，或同一 App 窗口）自动聚合成时间序列，挑任意一张看大图，或选 A / B 两张做**并排 / 滑块 / 差异高亮**三种对比，还显示差异像素占比。对比用的都是原图（不含标注）—— 它回答的是「画面本身变没变」
- **复制 Bug 报告** —— 和工具条「报告」同一份 Markdown 模板

**智能脱敏**：每张截图落库后自动检测敏感内容 —— 邮箱、AWS 密钥、JWT 令牌、GitHub 令牌、API 密钥、银行卡号（Luhn 校验）、手机号、IP 地址、人脸，全走系统 Vision 框架，零联网。详情栏列出命中类型和脱敏摘要（如 `ab***@gmail.com`，原文绝不进全文索引），**一键打码**给每个命中区域生成马赛克层，作为新修订追加 —— 非破坏，随时回到打码前。

每张截图自动采集元数据：App 名 / bundleID / 版本、窗口标题、显示器信息，浏览器截图还会通过 AppleScript 异步回填网址（Safari / Chrome / Edge / Arc / Brave / Vivaldi，需「自动化」授权，失败静默跳过）。

双击一张截图进入**编辑器**：全量工具栏 + 图层面板（点选、删除、改文字）+ 历史版本列表，改完「保存为新版本」追加修订，和截图时画的、钉图上补的走同一条链。

### 自动化调用（URL scheme / 服务菜单）

Index 注册了 `index://` scheme，并保留旧 `macshot://` 兼容既有自动化。快捷指令的「打开 URL」、Raycast / Alfred、终端 `open` 都能调起：

```
open "index://capture"            # 立即截图
open "index://capture?delay=5"    # 延时 5 秒截图（只覆盖这一次）
open "index://gallery?query=终端"  # 打开图库并搜索
open "index://last/copy"          # 复制最近一张截图（含标注）
open "index://last/reveal"        # 在访达中显示最近一张
```

App 未运行时经 URL 打开会自动启动并执行命令。服务菜单里还有「用 Index 截图」（任何 App → 应用菜单 → 服务；刚构建后没刷新的话跑一次 `/System/Library/CoreServices/pbs -update` 或重新登录）。

局限：`last/*` 取图库当前列表第一张（受筛选影响）；`gallery?query` 只走精确搜索。没做 App Intents —— SwiftPM 手工组包缺少 Xcode 的 metadata 提取阶段，快捷指令发现不了 intent（已实验证实），URL scheme 是等价替代。

## 存储与数据模型

```
~/Library/Application Support/MacShot/
  originals/<sha256>.png    原图，写入后永不修改（内容寻址，天然去重）
  thumbnails/<sha256>.jpg
  index.sqlite              元数据 + 修订 + FTS5 全文索引
```

原图是不可变的字节。标注以**结构化图层**存在修订链里：

```
shot (原图元数据)
 └── revision  (append-only，parentID 指向上一版)
       └── layers: [Layer]   矩形/椭圆/箭头/直线/文字/高亮/马赛克/裁剪
                             /序号/聚光灯/测量/美化/水印/外壳
```

每次保存都是 `INSERT`，从不 `UPDATE` 旧记录 —— 编辑历史天然完整、可无限回溯。裁剪同样是一个图层，不动原图。只有交给用户的产物（剪贴板 / 钉图 / 导出）才由 `LayerRenderer` flatten 渲染一次。

派生属性（OCR 文本、分类、特征指纹、敏感区域、CLIP 向量等）走通用的 `shotAttribute` 表 + 独立 FTS 索引，搜索时 UNION 两张 FTS 表 —— 新的后处理器产出的文本自动可搜，不必改 schema 或查询。

## 架构

整个系统只有**几个注册制扩展点**，新功能一律挂在其中之一上，「加功能 = 加一个文件 + 注册一行」，不改中间的编排代码：

| 扩展点 | 回答的问题 | 例子 |
|---|---|---|
| `CaptureSource`（入口） | 像素怎么进来 | 立即截屏、延时截屏、滚动截图 |
| `CaptureAction`（出口） | 结果怎么出去 | 钉图、复制、保存、上传图床、Bug 报告、OCR 取字 |
| `CapturePostProcessor`（中间） | 落库后派生什么 | OCR、浏览器网址、自动分类、特征指纹、敏感检测、CLIP 向量 |
| `ToolbarControl`（控件） | 工具条上放什么 | 工具、颜色、粗细、美化、外壳、水印、撤销重做；上下文相关显隐 |

其它值得一提的决定：图层坐标用 phantom type（`Layers<CanvasSpace>` / `Layers<ImageSpace>`）区分，忘换算或换算两次都是**编译错误**而不是标注错位；绘制原语只存在于 `LayerRenderer` 一个文件，四条预览/导出路径同源；工具快捷键表只有 `AnnotationTool.shortcuts` 一份，设置页的说明文本由它生成；剪贴板、存盘面板、窗口生命周期等平台副作用各自收敛到 `Platform/` 下的单一实现。

依赖方向、契约的完整定义和落地阶段见 **[ARCHITECTURE.md](ARCHITECTURE.md)**。

## 已知边界

- 选区不支持跨显示器拖拽（限制在起始那块屏内）
- 图库里右键未选中的卡片，直接对该卡片出菜单，**不改变选中态**（不做 Finder 式的右键预选）
- 修订历史是线性链，`parentID` 已预留但 UI 未做分叉
- Firefox 取不到网址（不支持 AppleScript，需退回 Accessibility API）
- 语义搜索的 MobileCLIP 模型为英文训练，中文描述效果打折
- 上传没有进度 UI —— 动作触发后选区层已关闭，成功的反馈是链接进剪贴板
