# 图库 ⌘C / ⌘A 失效修复

*日期 2026-08-08 分支 `dev_meta_spark_1.2`*

## 现象

图库中选中一张或多张截图后按 `⌘C` 无反应，`Edit → 复制/全选` 持续置灰；右键 `复制图片` 正常。`⌘A` 同样不稳定，`CapsLock` 打开时必现。

## 根因

1. **精确相等误判**  
   `GalleryKeyboard.handle` 用 `flags == .command` 判定，`NSEvent.modifierFlags` 经 `deviceIndependentFlagsMask` 后仍可能携带 `capsLock/function` 位，大小写锁定打开即失配。`⌘A/⌘C/⌘⌫` 三处同病。

2. **无主菜单，无键等价载体**  
   工程以 `main.swift` 手写 `NSApplication` 启动，`LSUIElement` 常驻，`NSApp.mainMenu==nil`。`⌘C/⌘A` 仅靠 `NSEvent.localMonitor` 旁路，单点失效即无兜底，不符合 macOS `Edit → Copy/SelectAll` 经 responder chain 分发的惯例。

3. **菜单校验过严**  
   `GalleryWindowController.validate` 以 `GalleryKeyContext.current()==.library` 为条件，该条件要求 `keyWindow===galleryWindow && !(firstResponder is NSTextView)`。`NSSearchField` 的 field editor（`NSTextView`）获焦后点击卡片不自动 resign，`firstResponder` 仍为 `NSTextView`，即便 `selectedIDs` 非空仍判 `false` → `Edit` 灰。

## 修复

### 1. `Sources/Index/UI/GalleryKeyboard.swift`

新增
```swift
private func isCommandOnly(_ flags: NSEvent.ModifierFlags) -> Bool {
    flags.intersection([.command, .shift, .control, .option]) == .command
}
```
`⌘A/⌘C/⌘⌫` 三分支由 `flags == .command` 改为 `isCommandOnly(flags)`，忽略 `capsLock/function`。

### 2. `Sources/Index/App/AppDelegate.swift`

* `applicationDidFinishLaunching` 中调用 `setupMainMenu()`。
* `setupMainMenu()` 创建 `NSApp.mainMenu`：`App(关于/退出)` + `Edit(复制→NSText.copy: ⌘C / 全选→selectAll: ⌘A)` + `Window`。`LSUIElement` 时菜单仅 `regular` 期可见，但键等价始终生效。
* `AppDelegate` 实现 `copy(_:)/selectAll(_:)` 与 `validateMenuItem/validateUserInterfaceItem` 兜底：有文字选区时让 `NSTextView` 自处理，否则以 `GalleryWindowMode==.library && selectedIDs非空` 判定。`selectAll` 在文本框内直接让位。

### 3. `Sources/Index/UI/GalleryWindowController.swift`

* `copy(_:)` / `selectAll(_:)` 改以 `GalleryWindowMode.shared.mode==.library` 判定，不再受 `firstResponder/keyWindow` 限制；有选区即调 `GalleryBatch` 同一渲染口径（与右键一致）。
* `validateMenuItem` / `validateUserInterfaceItem` 同步改判 `mode==.library`，文字选区优先由 `NSTextView` 响应，无选区冒泡到图片路径。
* `selectAll` 标记 `override`（`NSResponder` 已有），`copy` 为新增 `@objc func copy`。

## 行为

* 图库 `library` 模式有选中 → `Edit` 亮，`⌘C` 复制成品（多张为多 `NSPasteboardItem`），`⌘A` 全选 `allMatchingIDs()`（全量而非分页已加载）。
* 搜索框/标签输入有文字选区 → `⌘C` 复制文字，`⌘A` 全选文字。
* 非 `library` 模式（编辑器/设置）→ 置灰，不抢编辑器快捷键。

## 后续加固

### 4. `Tests/IndexTests/GalleryShortcutTests.swift`（新增）

回归 `isCommandOnly` 的 4 类边界：纯 `⌘` 命中、`⌘+CapsLock/Function` 仍命中、`⌘+Shift/Option/Control` 拒绝、无 `⌘` 拒绝；为可测试将 `isCommandOnly` 改为 `nonisolated`。

### 5. `Sources/Index/UI/GalleryGrid.swift`

`handleTap` 选中后若 `firstResponder is NSTextView` 则 `window.makeFirstResponder(nil)`，使搜索框等文本输入显式失焦，后续 `⌘C` 走图片路径而非空文本路径。此前 `TapGesture` 不自动移走 field editor。
