# 图库选中标签（✅）间歇不显示修复

*日期 2026-08-20 分支 `dev_qwen38_27B`*

## 现象

图库中点击卡片后，右上角的蓝色勾选徽章（`selectionBadge`）有时不出现。用 trackpad 快速点击多张卡时复现率较高，鼠标精确点击时较少。

## 根因

`handleTap`（`GalleryGrid+Card.swift`）通过 `currentModifiers()` 判定修饰键：

```swift
func currentModifiers() -> NSEvent.ModifierFlags {
    NSApp.currentEvent?.modifierFlags.intersection(.deviceIndependentFlagsMask) ?? []
}
```

SwiftUI 的 `TapGesture` 回调不带修饰键信息，代码从 `NSApp.currentEvent` 反查。但 tap 回调执行时 `currentEvent` **不保证还是本次点击的 NSEvent**——它可能已被后续 `keyDown`（`GalleryKeyboard` 的 local monitor 在 runloop 中交错处理键盘事件）或 `scrollWheel` 覆盖。

典型触发路径：用户刚松开 ⌘ 就点击卡片 → tap 回调时 `currentEvent` 仍是那个 keyDown → `flags.contains(.command)` 为 true → 走 `selection.toggle(id)` 而非 `selection.select(only: id)` → 如果该卡之前已选中，toggle 把它取消 → ✅ 消失。

`shot.id == nil` 时 `handleTap` 静默 return 无日志，也是一个次要的不可观测路径。

## 修复

### `Sources/Index/UI/GalleryGrid+Card.swift`

新增 `MouseModifierCache`：用 `NSEvent.addLocalMonitorForEvents(matching: [.leftMouseDown, .rightMouseDown])` 在 **mouseDown 时刻**（点击手势的起点，此时 flags 一定属于本次点击）缓存修饰键。

```swift
@MainActor
final class MouseModifierCache {
    static let shared = MouseModifierCache()
    private var flags: NSEvent.ModifierFlags?
    private var monitor: Any?

    func install() {
        guard monitor == nil else { return }
        monitor = NSEvent.addLocalMonitorForEvents(matching: [.leftMouseDown, .rightMouseDown]) { [weak self] event in
            self?.flags = event.modifierFlags.intersection(.deviceIndependentFlagsMask)
            return event
        }
    }

    var cachedFlags: NSEvent.ModifierFlags? { flags }
}
```

`currentModifiers()` 改为读缓存：

```swift
func currentModifiers() -> NSEvent.ModifierFlags {
    MouseModifierCache.shared.cachedFlags ?? []
}
```

`handleTap` 的 `guard let id` 失败路径加 `NSLog`，`shot.id == nil` 不再静默吞掉。

### `Sources/Index/UI/GalleryGrid.swift`

body 上加 `.onAppear { MouseModifierCache.shared.install() }` 安装 monitor。

## 设计理由

与 `GalleryKeyboard` 用 NSEvent local monitor 而非 SwiftUI 手势的理由一致（`GalleryKeyboard.swift:9-11` 注释：NavigationSplitView 里焦点会被侧边栏 List 和搜索框来回抢，网格自身拿不稳焦点）。修饰键的读取同理——SwiftUI 手势层拿不到可靠的修饰键，必须在 AppKit 事件层取值。
