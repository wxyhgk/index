# 剪贴板历史面板横向滚动与关闭修复

*日期：2026-08-21；验证版本：0.1.14*

## 背景

剪贴板历史面板（⌘⇧V 唤起）采用 Paste 式横向卡片流布局。上线后遇到两个连续问题：

1. 面板无法关闭——按 Esc、点击面板外面都没有反应；
2. trackpad 放在面板上无法左右滑动，后面的卡片看不到。

## 问题一：面板无法关闭

### 现象

按 `⌘⇧V` 唤出面板后，按 Esc 或点击面板外部区域，面板不消失，只能重启 App。

### 根因

面板使用 `NSPanel` + `.nonactivatingPanel` + `orderFrontRegardless()` 显示。`nonactivatingPanel` 让窗口不激活所属 App，键盘事件仍发给之前的 App，`NSEvent.addLocalMonitorForEvents` 收不到 Esc/←→/Enter。

### 修复

1. `show()` 中加 `NSApp.activate(ignoringOtherApps: true)` + `makeKeyAndOrderFront(nil)`，让面板成为 key window 接收键盘事件（Index 是 LSUIElement menu bar App，激活不跳 Dock）。
2. 加 global monitor 监听 `.leftMouseDown` / `.rightMouseDown`，点击面板外面自动关闭。
3. monitor 的 install/remove 收口到 `installMonitors()` / `removeMonitors()`，`close()` 时统一清理。

## 问题二：trackpad 无法横向滑动

### 现象

鼠标/trackpad 放在面板卡片区域，左右滑动不产生横向滚动，只能看到前几张卡片。

### 排查过程

依次尝试了以下修复，均未解决：

1. 去掉 `isMovableByWindowBackground = true`（怀疑窗口拖拽拦截鼠标事件）；
2. 去掉 `.nonactivatingPanel` styleMask，只保留 `.borderless`；
3. 加 `override var canBecomeKey: Bool { true }`（`.borderless` 窗口默认不能成为 key window）；
4. 去掉搜索框自动聚焦（TextField 获得焦点后拦截 scroll 事件）。

### 根因

SwiftUI 的 `ScrollView(.horizontal)` 在 `NSPanel` + `NSHostingController` 中，trackpad 横向滑动（`scrollWheel` 事件带 `deltaX`）不总是被正确转发给内部的 `NSScrollView`。这是 AppKit 与 SwiftUI 混用时的事件路由问题，与窗口的 key/active 状态无关。

项目中 `EditorFilmstrip` 已有同类问题的处理（`EditorFilmstripWheelBridge`），但它只处理纵向滚轮转横向，不处理 trackpad 原生横向滑动。

### 修复

新增 `ClipboardHistoryScrollBridge`（`NSViewRepresentable`），挂在 `ScrollView` 的 `.background` 上：

- 用 `NSEvent.addLocalMonitorForEvents(matching: .scrollWheel)` 拦截面板内的滚动事件；
- trackpad 横向滑动（`deltaX` 为主）直接驱动横向滚动；
- 鼠标纵向滚轮（`deltaY` 为主）也转成横向（放大 18 倍），让普通鼠标也能左右翻卡片；
- 手动写 `NSScrollView` 的横向 clip bounds（`clipView.scroll(to:)` + `reflectScrolledClipView`）；
- 通过 `enclosingHorizontalScrollView` 向上查找真正有横向溢出的 `NSScrollView`，避免误命中；
- 带 modifier 检查，Shift+滚轮等系统行为不拦截。

## 文件拆分

原 `ClipboardHistoryPanel.swift`（570 行）拆为 4 个文件，便于后续扩展：

| 文件 | 职责 |
|------|------|
| `ClipboardHistoryPanel.swift` | NSPanel 窗口 + 键盘/鼠标 monitor |
| `ClipboardHistoryViewModel.swift` | 数据加载、搜索、过滤、复制/删除/固定动作 |
| `ClipboardHistoryView.swift` | 顶部栏 + 卡片流布局 + ScrollBridge |
| `ClipboardHistoryCard.swift` | 单张卡片（标题栏/内容/底部） |

- `./build.sh debug` 构建替换后，`⌘⇧V` 唤起面板，Esc 关闭、点击外面关闭、trackpad 左右滑动均正常。
