# 跨显示器截图（B 呈现 + A 坐标模型）

日期：2026-10-18

## 目标

保留 Index 现有的「每块屏一个 overlay + 各自冻结帧」呈现方式（B），
但选区本身使用一个跨屏的虚拟坐标模型（A）：

- 选区可以拖出当前屏幕，落到相邻显示器上；
- 每块屏只绘制「全局选区 ∩ 本屏」；
- 输出把各屏冻结帧按全局坐标拼接成一张图；
- 不引入跨屏大窗口，避免 AppKit 单 backing scale / 单 Space 归属的问题。

## 实现

1. **全局选区边界**
   - `SelectionModel` 增加 `selectionBounds`（所有屏幕 frame 的并集包围盒）；
   - `bounds` 仍是本屏 `snapshot.frame`，负责绘制与局部坐标换算；
   - 拖拽 / nudge / 多边形 / 历史恢复全部改为夹紧到 `selectionBounds`。

2. **活动屏 + 广播**
   - `SelectionOverlayController` 记录 `activeView`；
   - 活动屏每次 `redraw()` 通过 `onSelectionChanged` 把
     `phase / rect / polygon / guides / dragOrigin / cornerRadius` 同步给其它屏；
   - 其它屏 `adoptSelection(from:)` 后只重绘，不回写；
   - `setInactive` 不再 `reset()`，切屏不会丢掉全局选区。

3. **非活动屏的呈现**
   - 保留压暗与选区边框；
   - 隐藏控制点、圆角绿点、尺寸标签、参考线与工具条；
   - 标注仍绘制（来自各屏自己的 annotation state）。

4. **输出拼接**
   - 新增 `MultiDisplayComposer.stitch`：按全局坐标裁每屏并画到统一画布；
   - 输出 scale 取活动屏（拖拽起点屏）的 scale；
   - 屏幕之间的空档保持透明；
   - 每屏标注先按本屏裁剪导出，再平移到拼接图坐标后合并。

5. **单屏动作收敛**
   - 录屏 / 长截图 / GIF 只接受单屏：跨屏时 region 收敛到活动屏交集，
     避免把跨屏矩形交给只认识单 display 的录制器；
   - 自动马赛克同样只处理活动屏。

6. **工具栏跟随**
   - 跨屏选区确认时，工具栏切到指针所在且与选区相交的屏；
   - 单屏保持原有行为。

## 测试

- `CrossDisplaySelectionTests`：跨屏拖拽、虚拟边界夹紧、adopt 同步、
  切屏不丢选区、跨边界 nudge。
- `MultiDisplayComposerTests`：统一 scale 拼接、空档透明、标注层偏移。
- `./scripts/check.sh` 全部通过（619 tests，6 skipped）。

## 已知边界

- 混合 DPI：输出以活动屏 scale 为准，其它屏缩放绘制；标注暂按输出 scale
  导出，跨不同 scale 时可能有比例误差（下一步需要按每屏 native scale 导出再缩放）。
- 多边形输出仍按外接矩形裁剪（沿用单屏既有行为）。
- 跨屏时窗口归因可能为空，元数据按活动屏 + 区域最佳匹配兜底。
- 跨屏移动选区时，非活动屏上的标注不会跟随平移（活动屏的标注会）。
- 真实跨屏拖拽、四屏排列、确认后输出需要手动验证。
