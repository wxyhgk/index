# 选区圆角手柄重做

日期：2026-10-18

## 旧交互的问题

- 四个角各有一个外侧控制点，位置是 `max(radius + 8, 16)`：**半径越大手柄越远**，
  拖拽时目标在移动。
- 手柄在选区外侧，贴边或全屏时落到屏幕外，抓不到。
- 抓取瞬间按「手柄到角的距离」重算半径，半径会跳 2–6pt。
- 四个手柄改的是同一个统一半径，视觉上像四个独立控制点。
- 没有任何半径读数或复位方式，只能精确拖回 0。

## 新交互

- **单个手柄**，固定在选区左上角内侧（内缩 22pt，小选区按 1/3 缩小），
  永远在选区内、不随半径移动。
- 拖拽用**增量**：抓住时记录起始半径与起点，向左上拖增大、向右下拖减小；
  投影到对角线，斜拖也跟手。
- **双击**复位为 0；悬停手柄时**滚轮** ±1pt。
- 拖拽/悬停时在柄旁显示「圆角 N」；半径 > 0 时也显示。
- 四个角保留淡淡的 1/4 弧线，只作「四角统一」的预览。
- 拿标注工具时手柄不出现，不抢画布点击。
- 选区小于 40pt 不显示手柄（没有可用空间）。
