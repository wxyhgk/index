# 选区圆角交互重做

日期：2026-10-18

## 旧交互的问题

- 四个角各有一个**外侧**控制点，位置是 `max(radius + 8, 16)`：半径越大手柄越远，
  拖拽时目标在移动。
- 手柄在选区外侧，贴边或全屏时落到屏幕外，抓不到。
- 抓取瞬间按「手柄到角的距离」重算半径，半径会跳 2–6pt。
- 手柄常驻显示，和四角的缩放手柄挤在一起。
- 没有半径读数或复位方式。

## 新交互

- **鼠标进入选区**（确认态、未拿标注工具）时，四角内侧各出现一个**绿色小点**
  （内缩 12pt，小选区按 1/4 缩小），拖任意一个点调整统一的圆角半径。
- 向选区内侧拖（把角往里收）= 增大，向外拖回到直角；用**增量**记录起点，抓住绿点时半径不跳。
- **双击**绿点复位为 0；悬停绿点时**滚轮** ±1pt。
- 拖拽/悬停时显示「圆角 N」标签（半透明白底黑字）。
- 鼠标移出选区、或切到标注工具，绿点自动消失。
- 绿点 8pt（hover 11pt），`systemGreen` 填充 + 半透明白描边；不遮挡内容。

## 验证

  抓取不跳变、向内夹到 0、最大半径、滚轮步进。
- `./scripts/check.sh` 全部通过（611 tests，6 skipped）。
