# Index 图库 —— 目标视觉稿拆解（用户提供的设计图）

> 这份文档是把用户给的一张设计图逐块量化成文字，供多个并行 agent 共用。
> 数值是从 1586×992 的设计图上量出来的估值，**按比例落地即可，不必像素级复刻**；
> 括号里给出取整后的建议值。凡与 `docs/spatial-ui-spec.md` 冲突之处，本文件优先
> （那份规格的**原则**仍然有效：内容层不上玻璃、每窗一个 behindWindow 材质、
> 深色靠亮度阶梯、克制的动效幅度）。

整体印象：**深色、全定制窗口 chrome、所有功能区都是"浮在深底上的圆角卡片"**，
面板之间留出可见的间隙（不是传统 macOS 那种齐平分栏）。

---

## 0. 全局

| 项 | 值 |
|---|---|
| 窗口底色（深色） | 近黑，约 `#0D0D0F`。所有浮起面板都比它亮一档 |
| 浮起面板底色 | 约 `#17171A` ~ `#1C1C1F`（比窗底亮 4~8 个 RGB 点） |
| 面板圆角 | 16~18（用 `DS.radiusPanel`=14 偏小，建议新增或直接用 18 = `DS.radiusModal`） |
| 面板描边 | 1px，白 6%~10%，顶边略亮（沿用既有 rim 渐变思路） |
| 面板间距 | 12~16（用 `DS.s3`/`DS.s4`） |
| 强调蓝 | 系统 accent（图中是 `#0A84FF` 一类） |
| 浅色模式 | 设计图只给了深色。**必须同时实现浅色**：窗底用系统窗背景色，面板用纯白 + 阴影，描边转为浅色侧的低不透明黑 |

## 1. 顶栏（完全自绘，取代系统工具栏）

高约 72。三段式布局：

- **左**：红绿灯按钮（系统的，位置留出约 80pt 安全区），其后是文字 logo「Index」，17pt semibold。
- **中**：搜索胶囊，宽约 460、高 38、全圆角。内含放大镜图标 + 占位文字「搜索截图、应用或文字」+ 右端 `⌘K` 快捷键徽章（小号、灰、带浅色圆角底）。
- **右**：三件，依次
  1. 筛选按钮（漏斗图标，36×36 圆角方）
  2. 视图切换分段控件（两个图标：网格 / 列表，装在一个胶囊里，选中项有浅色底）
  3. 头像圆形 32 + 右侧小三角（本项目没有账号体系 —— **这一项改成"更多/设置"入口**，见下方"落地取舍"）

顶栏本身**不画背景色块**，直接坐在窗口底色上。

## 2. 左侧图标轨（新结构）

窗口最左侧一条**竖向圆角卡片**（不是贴边的传统侧栏）：

- 位置：距窗左约 8，距顶约 150，向下延伸到接近窗底（约 860），宽约 56，圆角约 20。
- 内容：一列 44×44 的圆角方图标按钮，**每个图标下方跟一个小号计数数字**（灰色，11pt）。
  图中依次是：全部截图(49) / 收藏(星,无数字) / 浏览器(33) / 笔记(7) / 终端(1)，
  最底部固定一个设置齿轮。
- **选中态**：该图标底为强调蓝实心圆角方，图标转白。
- 语义：这一列 = 「资料库 + 高频分类」的快捷入口。

## 3. 左侧标签面板（浮动、可展开）

图标轨右侧**叠着**一块浮动圆角卡片（不是并排的第二栏，它压在内容之上）：

- 位置：紧邻图标轨右边（x 约 64 起），顶部约 195，高度自适应内容，宽约 168，圆角 16。
- 内容：与图标轨同源的一列**带文字标签**的行：图标 + 名称 + 右对齐计数。
  行高约 40，选中行有浅色圆角底。
- 判断：它是图标轨的「展开态」。**落地建议做成可折叠**：默认展开，点图标轨顶部的按钮（或 ⌘\）收起，收起后只剩图标轨。

## 4. 内容区

- **大标题**：「全部截图」约 34pt bold，右侧跟一行小字「49 个项目」13pt 灰。
- **筛选胶囊行**：四个下拉胶囊（最近 ▾ / 应用 ▾ / 类型 ▾ / 标签 ▾），高 34、全圆角、深色底、13pt 文字 + `chevron.down`。
- **时间分组**：「今天」「昨天」等分组标题，15pt semibold，偏灰白。
- **卡片**：
  - 缩略图圆角 10，**没有卡片底色**（图片直接浮在深底上），也没有外框。
  - 文字**在缩略图下方、左对齐**：第一行 App 名 12pt 白，第二行时间 11pt 灰。
  - 高度不等（不同截图比例不同），呈**参差网格**观感 —— 与现有瀑布模式接近。
  - **选中态**：整个单元格外包一圈 2px 强调蓝圆角框（圆角约 12，比缩略图大一档），
    右上角一个强调蓝实心圆形勾选徽章（直径约 22，白色勾）。
    注意：图中的勾在**右上角**，与我们现在的左上角不同 —— 按图改到右上。

## 5. 底部浮动工具条

**居中悬浮的圆角胶囊**（不是贴底的整条 bar）：

- 宽约 540、高 56、圆角 16，深色底 + 细描边，浮在内容之上，距窗底约 24。
- 内容分两组，中间留空：
  1. 左：三图标分段控件（网格 / 分栏 / 列表），装在一个内嵌小胶囊里，选中项浅色底。
  2. 右：缩放滑杆 —— 左端小图标、中间滑杆（约 200 宽）、右端大图标。

## 6. 右侧详情面板（浮动卡片）

**一块独立的浮动圆角卡片**，不是齐平的 inspector 栏：

- 位置：距窗右约 30，距顶约 118，向下到约 810，宽约 370，圆角 18。
- 结构自上而下：
  1. **右上角关闭按钮**（✕，圆形浅底，约 28）
  2. **预览区**：当前截图的等比预览，占面板上部约 190 高，圆角 12，四周留白
  3. **动作行**：主按钮「✏️ 编辑」为强调蓝实心胶囊（约 100×34），其后四个圆形图标按钮
     （收藏星 / 钉图 / 分享 / 更多），各约 34，浅色圆底
  4. **元信息列表**：每行 = 18pt 图标 + 13pt 文字，行高约 38，图中依次是
     - 真实 App 图标 + 「Google Chrome」
     - 地球图标 + 来源页标题（如「同济大学图书馆」）
     - 日历图标 + 「2026年7月29日 · 20:17」
     - 图片图标 + 「2208 × 242 px」
     - 文字图标 + 「识别文字 106 字」
  5. **标签胶囊行**：小号胶囊（如「浏览器」「网页」），深色底、灰字
  6. **底部行**：分隔后一行「查看全部信息 ›」，整行可点，右侧 chevron

## 落地取舍（实施 agent 必须遵守）

1. **头像换成设置/更多入口** —— 本项目没有账号体系，画一个假头像是欺骗性 UI。
   用「⚙️ 设置」或「⋯ 更多」圆形按钮占这个位置。
2. **浅色模式必须一并实现**，不能只做深色。设计图只提供了深色答案，浅色按
   `docs/spatial-ui-spec.md` §8 的原则推导（浅色靠阴影分层、面板用纯白）。
3. **无障碍**：ReduceTransparency 时面板转实色；ReduceMotion 时收起/展开动画降级。
   既有的 `DS.Motion.*(reduced:)` 与 `VisualEffectBackground` 的降级逻辑照旧使用。
4. **性能红线不变**：几百张卡片的网格里，卡片仍然**不许**用 Material 做底
   （现在图上卡片干脆没有底色，正好更省）；每窗口最多一个 behindWindow 材质。
5. **不要为了像而牺牲已修的东西**：固定列数防振荡、拖动时不写父层 state、
   投放走 `ShotIDPayload`、`.draggable` 载荷必须廉价 —— 这些都是事故换来的，全部保留。
6. 设计图里没画的功能（多选批量面板、相似 sheet、空态、语义搜索切换等）**不许删**，
   按同一套视觉语言（浮动圆角卡片 + 深底）自行推导。
